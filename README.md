# Deep Learning para Detecção de Cálculo Renal em Imagens de CT

Projeto desenvolvido durante o Estágio Supervisionado do curso de Ciência da Computação da PUC Minas.

## Objetivo

Identificar cálculos renais em exames de Tomografia Computadorizada utilizando técnicas de Deep Learning.

## Tecnologias

- Python
- TensorFlow/Keras
- U-Net
- YOLOv8
- OpenCV

## Dataset

KSSD2025 – Kidney Stone Segmentation Dataset.

## Resultados

- Segmentação com U-Net
- Dice Score ≈ 0.92
- Detecção utilizando YOLOv8
